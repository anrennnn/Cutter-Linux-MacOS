## Descargas

| Sistema | Archivo |
|---|---|
| **Mac con Apple Silicon (M1–M4)** | `Cutter-…-macOS-AppleSilicon.dmg` |
| **Mac con Intel** | `Cutter-…-macOS-Intel.dmg` |
| Debian, Ubuntu, Linux Mint, Pop!_OS, Zorin | `cutter-linux_…_all.deb` |
| Arch Linux, CachyOS, EndeavourOS, Manjaro | `cutter-linux-…-any.pkg.tar.zst` |
| Fedora, Bazzite (rpm-ostree) | `cutter-linux-….noarch.rpm` |
